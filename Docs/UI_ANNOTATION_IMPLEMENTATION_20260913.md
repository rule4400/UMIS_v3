# 画像指示によるUI変更・検証記録（2026-09-13）

## 対象と互換性

ユーザー提示の「UMIS UI debug.png」の黄色い注記をUI要件として実装。取り込み・評価・リネーム等の既存ワークスペース構成は維持する。今回の開発版は `0.2.0-alpha.7`、作業ブランチは `feature/ui-annotation-20260913`。

カード初期化の認定境界、コピー／SHA-256検証、Adobe XMP、Finderカラーの安全条件は緩和しない。DB／Project JSON schemaの変更なし。旧公証済み `v0.2.0-alpha.6` と `dist/release-20260913-alpha6` はそのまま保持する。今回の開発版を公証済みとは扱わない。

## 要件との対応

| 画像の指示 | 実装 |
| --- | --- |
| 会場をプルダウンに | プロジェクト内の登録会場をUUIDで選択。＋で会場追加。未指定・未登録時も操作できる。以前の会場名は上書きしない。 |
| ボタンでモーダルを開き、カメラマン・カードNoを選択 | 2列のボタン選択画面。登録カード選択で対応撮影者を呼び出し、撮影者だけ変更可能。新しい名前／カード番号も入力可能。ローカル下書きを「決定」で一括適用し、キャンセルは無変更。 |
| 接続中のSDカードを自動で読み込み対象に | 起動前から接続中のボリュームも検出。既存の強い物理IDと永続隔離照合に合格したSDが1枚だけで、取り込み画面が前面かつ操作可能ならスキャン。複数枚は候補ボタンから利用者が選択。 |
| プロジェクトで選んだ保存先を保持 | 保存済みプロジェクトでは保存先の変更だけを保存。他の未保存編集を勝手に保存しない。切替時に各プロジェクトの保存先を復元。新規プロジェクトは初回の「保存」が必要と表示。 |
| 種類をプルダウンではなくボタンで | すべて・動画・写真・RAW・音声・その他を常時表示。狭いペインでは折り返す。取り込み／評価のフィルター状態は独立。 |
| 日付ボタンでシーン表示切替 | 既存モデルの撮影日番号に合わせ、1日目〜4日目・その他を表示。読み込んだ5日目以降も利用可能。別の日に切り替えた時点で非表示シーンの選択を解除する。カレンダーの年月日ではなく既存の撮影日番号を使う。 |

撮影者・カード・会場の登録内容はプロジェクト保存で保持する。SD管理VPSへの新しい通信や、他プロジェクトを横断する登録マスタの変更は今回含めない。

## あわせて修正した不具合

- プロジェクトPickerの値を読み込み前に更新していたため、読み込み失敗で表示中プロジェクトと削除対象が食い違い得た。読み込み適用後だけIDを更新し、削除の表示条件・実行直前の両方でID一致を確認する。
- LANシーン更新で選択が毎回先頭へ戻っていた。同じUUIDが残れば選択と所属日を保持し、削除されたUUIDは選択解除する。
- 新しいモーダルの表示元をウインドウ幅で入れ替わらない親Viewへ配置。コンパクト／通常レイアウト切替による編集下書きの消失を防ぐ。
- 撮影者未指定／無効な撮影者に対応するカードの読込時は、無関係な先頭撮影者で補わない。
- Swift 6の並行処理検査に合わせ、ウインドウ監視の解除で非Sendableな通知tokenを非isolated deinitから参照しない構造にする。

## 自動SD選択の安全境界

- 物理カードの種類、現在の挿入世代、MediaUUID・VolumeUUID、親デバイス証跡、永続隔離照合等の既存条件を要求する。表示名やパスだけでSDと判断しない。
- 接続検出と登録処理がすべて完了するまで待ち、500msの集約待機を行う。別カードが隔離照合に失敗した場合も、勝手に残り1枚を選ばない。
- 手動選択済みの読み込み元は自動変更しない。自動選択したカードを抜いた場合のみ自動選択元を解除し、抜去時の取消・隔離・挿入世代失効は維持する。
- 別ワークスペース、別ウインドウ、プレビュー、モーダル、OSのフォルダ選択画面、処理中には自動開始しない。
- 自動化するのは読み込み対象の選択とスキャンのみ。コピー・初期化・取り出しは自動実行しない。
- 汎用USBリーダー、識別情報不足、read-only、複数パーティション等は自動対象外になり得る。安全照合の失敗を通常フォルダ読み込みへ自動で降格せず、「選択…」で手動指定を案内する。

実際のカード／リーダーの認定は今回のソフトウェアテストとは別。すべてのSDリーダーで自動認識できるという保証はしない。

### 実画面で確認した内容

- 新ビルドを起動し、会場のプルダウン、6種類のフィルターボタン、5つの日別ボタンが表示されること。
- 撮影情報を入力後、Escapeでキャンセルし、撮影者／カードが未指定のままであること。
- カード `0007` と撮影者を決定し、再度開くと登録済みのボタンとして選択されること。
- 日本語の撮影者名を設定し、取り込み画面に同じ名前と `0007` が表示されること。
- 会場追加の空欄では決定できず、入力後に有効になり、追加後のプルダウンに日本語名が表示されること。
- 「写真」を選択した表示状態と、「2日目」でD201だけが表示されること。
- 評価画面にも同じ6種類のボタンが表示され、サイドバーと下部評価／カラー操作が画面内に残ること。

実画面検証は未保存の新規プロジェクトで実施し、検証入力は新規状態へ戻した。既存の保存済みプロジェクト、実素材、SDカードへの書き込み・削除は行っていない。保存先の保存／再読込は自動テスト用の一時ストアで検証し、ユーザーの本番プロジェクトを使った保存先変更は行っていない。
