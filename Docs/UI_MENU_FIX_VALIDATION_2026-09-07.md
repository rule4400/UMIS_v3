# 評価画面消失と周辺UIの修正・検証（2026-09-07）

## 対象と再現

ユーザー報告「評価メニューを開くとメニューが見えなくなる」を、既存ローカルQAアプリで実画面・クリックにより再現した。上部のmacOS標準「評価」メニューの削除ではなく、サイドバーから「評価・タグ」を開くと、サイドバー／ヘッダー／下部評価操作がウインドウ外へ配置される不具合だった。AXには要素があるが、サイドバーのクリックは `cannotClickOffscreenElement` となり、キーボードで取り込みへ戻すと表示が復帰した。

フォルダリネームでも同型の上下見切れ、小さいウインドウの取り込み画面では左右パネルの見切れを確認した。

## 原因と変更

- 評価／リネーム説明文の `fixedSize(horizontal: false, vertical: true)` を除去し、ゼロ幅の最小サイズ計測で長文が縦へ膨張しないようにした。取り込み準備メッセージにも同型修正と全文のヘルプを追加。
- RootViewに実ウインドウ寸法の境界を設けた。GeometryReaderだけでは本文の過大最小高は解消しなかったため、本文側の修正も必要だった。
- `safeAreaInset` では下部操作にステータスが重なる状態が残ったため、VStackでステータスの高さを実際に予約した。
- 取り込みの中央最小幅を縮小しても、狭いウインドウの入れ子HSplitViewが過大な幅を保持する状態が残った。詳細領域が1100pt未満でシーン表示中は、入力230pt／シーン280pt／中央は残余幅のコンパクト配置を使用する。広いウインドウでは従来の可変ペイン幅を維持。
- コマンドをFocused Sceneの状態へ接続し、別の設定ウインドウやプレビューから背景の評価・フォルダ選択等が発火しないようにした。無効理由を評価メニューに表示。編集欄の⌘Aは文字選択を優先。
- 検索後に上部「選択1件」と下部「選択0件」が不一致になる症状を実画面で発見。選択の可視IDとの積集合をAppModel内で同期更新し、SwiftUIの後発onChange依存を除去した。
- 非対応コーデックの動画を開くと代替アイコンだけが表示されたため、再生不可・代替アイコン・低品質プレビューを区別した案内を追加した。再生可能な動画のポスターだけが代替画像の場合は警告しない。

## 実画面で確認した範囲

CUAでローカルQAアプリを操作。カードの消去・取り出し、実素材の書き換えは実施していない。

| 検証 | 結果 |
| --- | --- |
| 最小1080×752ptのウインドウ（内容700pt）で5画面を順番に表示 | サイドバー／ヘッダー／各画面の下部操作を確認。長い入力フォームはスクロール領域として表示 |
| 評価画面への切り替えとサイドバーからの復帰 | 操作成功。元の画面消失を解消 |
| リネームの入力欄・計画作成／実行ボタン | 小さいウインドウでも見切れなし |
| 小さい取り込み画面の入力・素材・シーン・下部開始ボタン | コンパクト配置で左右の見切れを解消 |
| テストJPEGに評価メニューから3つ星を保存 | 更新成功。ファイル内 `xmp:Rating="3"` も確認 |
| 同テストJPEGへFinderブルーを保存・メタデータ再読込 | 状態維持。FoundationからlabelNumber=4を確認 |
| JPEG選択後に「動画」で検索→解除 | 上下の件数が一致。隠れた選択は解除され、検索解除後にも復活しない |
| ⌘F | 素材検索欄へフォーカス移動 |
| 通常JPEGプレビュー・Escで閉じる | 画像／情報を表示し正常に閉じる |
| 8BPSコーデックのテストMOV | 再生不可と代替アイコンの理由・Finderでの確認方法を表示 |
| プレビュー中の評価メニュー | 理由を表示し評価・再読込を無効化 |
| 写真選択を残して別設定ウインドウを開く | 評価とファイル選択メニューが無効。⌘1で背景JPEGの3つ星が変化しない |
| 別設定ウインドウの⌘A | 編集欄の文字を選択。閉じた後も背景素材は元の1件選択を維持 |

素材の保存検証はAdobeXMPの同梱テストfixtureを専用一時フォルダへ複製して実施し、リポジトリ内fixture原本を保持した。UI自動テストは `AppModel(initializeServices: false)` を使い、ユーザーの永続ジャーナル・カード監視・LANサービスを起動しない。

## 自動検証

- `RootViewViewportLayoutTests`: 各画面のゼロサイズ最小高、1080×700／1360×860で実NSView・全NSSplitViewのフレームが表示範囲内であることを検証。3件成功。
- `AssetBrowserSelectionInvariantTests`: 取り込み／評価の検索・カテゴリ・一覧更新と選択解除、2万件で不要な選択revision更新がないことを検証。
- `MediaPreviewNoticeTests`: 通常写真、低品質画像、非対応動画／音声、再生可能動画の代替ポスターを検証。
- `Vendor/AdobeXMP/Scripts/verify_xcframework.sh`: 成功。
- `swift test --parallel`: 全304項目、終了コード0。大文字小文字を区別する専用APFSボリュームが必要な1項目は環境条件によるskip。
- `swift build --configuration release -Xswiftc -warnings-as-errors`: 成功。
- `git diff --check`: 成功。
- Universal 2成果物の情報はパッケージ作成後に追記する。

## 検証の境界

- 実機確認はこのMacでのローカルQA版。Intel実機、macOS 13実機、VoiceOverによる読み上げ通し試験、実Adobe製品との往復操作は別途必要。
- カード初期化・取り出し、LAN本番適格性、SD管理APIの製品上の制約は変更していない。
- 既存の公証済み配布物は置き換えない。本修正のQA版はローカル検証用として別ディレクトリへ出力する。
