# RINKAN UMIS：現行解析とmacOS Swift再設計

作成日: 2026-08-26  
解析対象: RINKAN UMIS v1.1.103（受領ZIP名はv1.1.98だが、同梱中の最新版はv1.1.103）

## このフォルダの目的

このフォルダは、Flet/Python版RINKAN UMISをmacOS専用のSwiftアプリへ再構築する前段として作成した、現行仕様・不具合・データ構造・性能・安全性・新設計・移行試験・署名公証・SD管理システム連携の基準資料です。

現行アプリに「書かれている機能」と「実際に動く機能」を分け、未使用設定、未接続UI、表示と実処理の不一致も仕様として記録しています。新Swift版は、見た目と業務フローを概ね維持しながら、ファイルの取り違えや破損を防ぐトランザクション設計へ置き換える前提です。

## 公開repositoryの証拠参照

文書中の`legacy-source/`、`legacy-package/`、`sd-handoff-source/`、`sd-handoff-package/`、`workspace/`は、非公開の受領証拠を示す論理名です。個人のローカルパス、受領archive、VPS credential、production dataはGitHubへ同梱しません。ファイル名、行番号、SHA-256は非公開証拠庫と照合するためのtraceとして保持します。GitHub上でこれらの論理link先が開けないのは意図した公開情報境界です。

## 判定ラベル

- **確認済み**: ソース、配布物、実動作、またはコマンド結果で直接確認した事実
- **不具合**: 現行の意図または表示と、実処理が明確に食い違うもの
- **設計判断**: Swift版で採用を推奨する方針
- **暫定**: 利用者環境や運用ルールの確認後に確定する項目
- **未確認**: 実カード、NAS、Intel Macなど、今回の隔離検証では実行していない項目

## 解析時の安全措置

- 元ZIPは変更していません。
- 展開した現行ソースにも変更していません。
- GUI検証は `RINKAN_UMIS_BASE_DIR` を一時ディレクトリへ向けた隔離環境で実施しました。
- 接続されていた実ボリュームは「読み込まない」を選び、スキャン、コピー、取り出し、初期化を行っていません。
- 負荷試験はアプリ自身が一時生成した30本の短い動画と200枚のJPEGだけで実施し、処理後に通常終了しました。
- 配布アプリのquarantine解除は `/tmp` 内の検証用コピーだけに実施しました。受領物の属性は変更していません。
