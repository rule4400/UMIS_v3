## 6. Runtime verification

### 6.1 Quarantine behavior

受領appのoriginalはquarantine付きです。そのままのmedia selftestはGatekeeper／runtime条件でSIGKILL 137となりました。`/tmp`へ作った検証copyだけに`xattr -cr`を実行すると、selftestは全項目passしました。original app／ZIPの属性は変更していません。

Selftest pass:

- bundled ffmpeg
- bundled ffprobe
- synthetic video generation
- ffprobe duration
- JPEG thumbnail
- 540p proxy
- HEIF roundtrip
- rawpy import
- flet-video import
- certifi CA bundle
- Flet desktop archive

このtestはruntime同梱の確認であり、copy、duplicate、cancel、erase、UI correctnessのtestではありません。

### 6.2 GUI inspection
